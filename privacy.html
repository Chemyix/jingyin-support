隐私政策

生效日期与最后更新日期：2026-10-18

婧音宝盒是一款管理与播放个人音频的工具。本 App 不要求注册婧音账号，不建立开发者自有的云端音乐库。曲库和设置主要保存在你的设备上；你主动配置的云存储、歌词服务及支持邮件会涉及相应的网络请求或信息传递。

本政策说明哪些信息用于什么功能、可能发送给谁，以及你如何管理这些信息。它不替代你选择的第三方服务商各自的隐私政策。

运营者本机资料联网服务支持邮件保留与删除你的权利

1. 运营者与联系方式

本 App 由个人开发者江伟 张提供。有关功能、隐私或个人信息处理的请求，请联系：768690360@qq.com。

2. 保存在设备上的资料

  • 音频与曲库信息：你主动导入或通过已配置连接访问的音频，以及歌名、歌手、专辑、文件信息、封面与歌词等，用于展示、搜索、整理和播放。
  • 整理和使用设置：歌单、喜欢关系、播放状态、外观主题、图标选择、缓存及歌词配置等，用于提供和保留你的使用偏好。
  • 存储连接：服务类型、地址、存储桶、目录范围等连接配置保存在本机。iOS 端的连接密码和访问密钥通过系统安全存储机制保存，用于你选择的远程服务认证。
  • 缓存与离线副本：按功能需要保存的封面、歌词、临时音频和你主动保存的离线音频。它们不会因此自动成为开发者云端资料。

本 App 当前实现未接入开发者自建的广告跟踪或用户行为分析系统。保存在本机并不意味着完全不联网；具体网络行为见下一节。

3. 你选择的联网服务

远程音频与对象存储

连接、验证、扫描、读取元数据、播放或下载时，App 会向你配置的服务端发送相应的目录或文件请求，并使用完成认证所需的凭据或签名。服务端也可能接收到 IP 地址、请求时间、访问路径和必要的协议头等网络信息。

服务可以是 WebDAV、阿里云 OSS、腾讯云 COS、Cloudflare R2、Amazon S3、OVHcloud Object Storage，或你自行部署的兼容服务。实际数据处理者、存储地区、权限和保留规则，以你填写的地址及服务商政策为准；选择某种接口类型并不表示开发者为该地址的运营方背书。

自定义歌词接口

只有在你添加歌词来源并开启联网匹配后，相关功能才会向你配置的接口发送必要的歌曲检索信息，例如歌名、歌手、专辑、时长及搜索关键字；接口还可能接收 IP 地址、请求时间、客户端标识和服务鉴权或会话信息。

支持的协议类型包括 LrcShare、LrcAPI / Lrc.cx 和 LRCLIB。官方 LrcShare 接口使用 App 授权，无需你填写 API Key；这并不意味着你的请求对服务提供方不可见。歌词接口不会因为提供歌词而获准接收你的个人云存储密码或访问密钥。

歌词服务可能记录访问日志；其保留期限、运营地区与数据用途需由对应服务方说明。请在启用前核实接口地址及其隐私政策。你可以关闭联网匹配或移除相应来源，停止后续由该功能发起的请求；此前已发送的数据和已获取的本地缓存不会因此自动从第三方或本机全部删除。

Apple 平台服务

App 分发、购买、TestFlight 和系统诊断等由 Apple 提供。Apple 可能依据你的系统设置及其政策处理相关资料，并通过平台向开发者提供部分购买汇总、反馈或诊断信息。具体以 Apple 的说明和你的选择为准：Apple 隐私政策。

4. 支持邮件与支持网站

当你主动发送反馈邮件时，开发者及邮件服务提供方会处理你的邮箱地址、邮件内容，以及你选择附加的截图或日志，用于回复、排查问题和必要的后续沟通。反馈邮箱使用 QQ 邮箱，邮件的传输及存储同时受其服务规则约束。

只需提供处理问题所必需的信息。请勿发送密码、访问密钥、API Key、私钥、证书、完整签名下载链接，或未经脱敏的敏感日志。

本支持网站不主动设置分析或广告跟踪脚本，不使用表单上传资料。网站部署至 GitHub Pages 后，GitHub 可能为提供托管、安全和访问服务而处理 IP 地址等访问日志；具体见 GitHub 隐私声明。点击邮件链接会调用你自己的邮件应用，不会自动发送邮件。

5. 保存期限、删除与备份

本机曲库、设置和离线资料通常保留至你修改、移除、清理，或受到设备存储及系统行为影响。临时缓存与主动保存的离线音频是不同类型，具体清理范围以 App 界面的操作说明为准。系统安全存储受 iOS 策略影响，仅卸载 App 不保证清除所有钥匙串项目；如需使远程授权失效，应在服务商处撤销或轮换对应凭据。

支持邮件保留至问题处理及必要后续沟通所需期间；你可以请求删除不再必要的支持记录。依法需要保留的资料可能有不同处理要求。远程服务方已经接收的信息，需要根据其政策向该服务方提出查询或删除请求。

整理备份由你主动导出并保管，可能包含歌名、歌手、歌单名称及喜欢关系，不包含音频文件或连接密码、访问密钥。它不等于完整设备备份。请勿在没有确认备份范围前卸载 App 或删除本地文件。

6. 安全与跨地区处理

我们通过系统安全存储、按功能限制凭据使用和避免无必要传输等方式降低风险，但无法承诺任何设备、网络或服务绝对安全。请优先使用 HTTPS、最小权限与只读访问凭据，并妥善保护设备。

你选择的云存储、歌词服务，以及 GitHub、Apple 和邮件服务可能在你所在地区以外处理资料。请在使用前确认相关服务的运营地区、访问规则和隐私保障。不建议将含有私密个人信息的文件名作为公开接口的检索内容。

7. 你的选择与权利

你可以管理本机曲库和歌单、移除连接、关闭联网歌词、按界面说明清理缓存，以及导出整理信息。对开发者因支持沟通持有的个人信息，你可以来信请求查阅、更正或删除，并提出适用法律规定的其他权利请求。我们会在适用法律要求的期限内处理；为保护资料安全，可能需要通过原联系邮箱等必要方式核实请求。

开发者不能代替你管理第三方云账号中的文件，也不能保证删除第三方独立持有的日志。移除本机连接与删除远程文件是不同操作。本政策不限制你依据适用法律享有的权利。

8. 未成年人

本 App 面向一般用户，不以儿童个人信息收集为目的。未成年人应在监护人指导下使用；如适用法律要求监护人同意，应先取得相应同意。如果你认为支持沟通中包含不应处理的儿童个人信息，请联系开发者核实并依法处理。

9. 政策变更

当功能或信息处理方式发生变化时，我们会更新本页面及日期。涉及重要变化时，将依据适用要求通过 App 更新说明、应用内提示或其他适当方式告知；如依法需要另行同意，会先取得相应同意。
