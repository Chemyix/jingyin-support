常见问题

婧音宝盒是否提供音乐资源？

不提供内置音乐曲库、盗版资源或音乐获取渠道。请导入或连接自己拥有、或已经获得使用授权的音频。你需要自行遵守音频及服务提供方的使用规则。

如何使用 WebDAV 或对象存储？

在 App 的资源页面添加连接，选择对应服务类型，按照表单填写服务地址及必要的认证信息。对象存储还需要正确的区域、存储桶和访问权限。优先使用 HTTPS，并查看表单下方的使用教程；连接失败时先核对地址、目录范围和权限。

联网歌词如何开启？

在设置中添加自定义歌词 API 的 HTTPS 基础地址，然后开启联网匹配。支持的接口协议包括 LrcShare、LrcAPI / Lrc.cx 和 LRCLIB。官方 LrcShare 接口使用 App 授权，无需用户填写 API Key。歌词服务由第三方提供，可能因限流、维护或内容匹配情况而暂不可用；请克制使用并遵守服务方规则。

没有网络时可以播放吗？

已在本机的音频，以及事先成功保存的离线歌曲，可以在无网络时使用。仅扫描出云端曲目、缓存封面或缓存歌词，不等于已经保存完整音频。

CarPlay 有哪些使用条件？

需要支持 CarPlay 的 iPhone 和车载设备，并安装包含 CarPlay 能力的正式 App。请先在手机完成音乐资源配置。若连接异常，请在停车后安全操作，并反馈设备型号、App 版本和具体发生步骤。

整理备份是否包含歌曲和连接密码？

整理备份用于保存歌单、喜欢等曲库整理信息，不包含音频文件或连接密码、访问密钥，也不能替代完整的设备备份。请妥善保管备份文件，避免在未备份前卸载 App 或删除本地音频。

如何处理隐私或删除请求？

本机资料可通过 App 中的曲库、连接和缓存管理功能分别处理。涉及支持邮件、个人信息或其他隐私问题，请发送邮件至上方邮箱。云服务端的数据或授权，需要在相应服务商处管理。详情见隐私政策。
